# Customer Shopping Behaviour Analysis

An end-to-end data analytics project focused on understanding customer purchasing patterns, preferences, and shopping trends using Python, PostgreSQL, and Power BI.

## Overview
The project explores customer shopping data to identify purchasing trends and generate meaningful business insights through data analysis and visualization.

## Dataset
Customer shopping behaviour dataset containing demographic information, product categories, purchasing habits, and transaction details.

## Tools & Technologies
- **Python:** Data cleaning and EDA
- **Pandas & NumPy:** Data manipulation
- **PostgreSQL:** SQL-based analysis
- **Power BI:** Interactive dashboard and visualization
- **Gamma:** Project presentation

## Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL analysis using PostgreSQL
5. Power BI dashboard development
6. Report and presentation creation

## Dashboard
Interactive dashboard presenting customer purchasing patterns, product performance, and key business metrics.

## Key Results
Analysis of customer preferences, purchasing trends, product categories, and customer segments to identify potential business opportunities.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Run the Jupyter Notebook.
4. Set up PostgreSQL and execute the SQL scripts.
5. Open the `.pbix` file in Power BI Desktop.
